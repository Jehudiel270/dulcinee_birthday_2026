# Dulcinée — The Crimson Garden

Expérience horror d’anniversaire en 3D avec portail, mausolée, statue et cimetière traversable. En mode plein écran, tous les textes disparaissent et il ne reste qu’un bouton rond minimal pour sortir. Les tombes sont construites avec socles, stèles, voûtes, croix et lanternes rouges à différentes profondeurs.

## Contrôles

- **Entrer dans le jardin** : active l’exploration et bloque le scroll de la page.
- **Glisser souris/doigt** : tourner la caméra.
- **Molette, flèches ou WASD** : avancer/reculer.
- **Plein écran** : passer en mode immersif sans textes.
- **×** ou `Échap` : sortir du plein écran.

Le site est responsive : les contrôles se réorganisent sur mobile et la scène occupe le viewport disponible.
